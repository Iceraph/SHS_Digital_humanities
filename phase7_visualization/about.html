What this website shows

This visualization brings together shamanism-related cultural features, spatial clustering, and language-family structure so you can explore how practices vary across cultures and regions.

2,687 cultures 19 features 8 clusters 3 data sources

How to read it

Colors identify cluster membership.

Search selects one feature at a time and updates the globe.

The tree groups cultures by language family and shows which clusters dominate each branch.

Globe

Spatial overview

The center panel places every culture on the map. Use the globe to inspect where cultures are located, whether they cluster spatially, and how selections change the view.

  • Click a point to inspect a culture.
  • Drag to rotate the globe or switch to 2D map mode.
  • Selected features and filters reduce the visible set.

Feature search

Feature-by-feature exploration

The left panel lets you search the coded shamanic features. Selecting a feature updates the map and the statistics panel so you can compare prevalence and spatial autocorrelation.

  • Search narrows the feature list.
  • Clicking a feature filters the globe to cultures where it is present.
  • The statistics card shows prevalence and Moran's I when available.

Phylogenetic tree

Language-family structure

The right panel shows a language-family summary. Branches are colored by dominant cluster composition, and clicking a family narrows the globe to that lineage.

  • Hover for cluster composition details.
  • Click a family node to filter the map.
  • The root summarizes the full language-family overview.

Legend

Cluster colors

The cluster legend maps each color to one of the eight inferred clusters. The same colors appear in the globe, the tree, and the feature summaries so you can follow the same group across the whole interface.

Filters

Combine views

Language family, cluster, and feature filters work together. That means a tree click, a dropdown selection, or a feature search can all narrow the same underlying data instead of replacing each other.
